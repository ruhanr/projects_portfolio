# Data Science Portfolio — Ruhan Rahman

This repository contains selected data science and machine learning projects focused on predictive modeling, data engineering, cloud integration, and model evaluation using real-world datasets.

## Core Focus Areas
- Data Engineering & ETL Workflows
- Regression & Classification Modeling
- Cloud Computing & API Integration
- Cross-Validation & Hyperparameter Optimization
- Geospatial Data Analysis & Visualization
- Time-Series Forecasting
- Model Interpretability

## Featured Projects

### Urban Infrastructure & Public Safety Modeling
Regression and classification models analyzing violent crime and pedestrian-vehicle accident hotspots across 239 Charlotte census tracts.  
**Techniques:** Spatial joins, feature engineering, cross-validation, grid search.

### Charlotte Gas Price Forecasting & Cloud-Based Analytics
Cloud-based data pipeline integrating historical AAA gasoline prices to forecast regional price trends across the Charlotte metropolitan area. Developed a regression model using 102 weeks of historical data to generate 52-week forecasts, with interactive geospatial visualizations.  
**Technologies & Techniques:** Python, AWS S3, REST APIs, linear regression, ArcGIS, data engineering.

### Income & Risk Classification Modeling
Comparative evaluation of classification models to predict income level and credit risk outcomes.  
**Techniques:** Logistic regression, SVM, decision trees, structured model validation.
